# JavaScript Packages for Pattern (Hatch) Fills

This project already uses the **`three`** package (Three.js) for WebGPU rendering.


| Package | Typical Use‑Case | Install Command |
|---------|------------------|-----------------|
| `hatch-pattern` | Generates SVG hatch patterns for D3, SVG, Canvas, etc. | `npm install hatch-pattern` |
| `patternomaly` | Pattern fills for Chart.js (dots, stripes, etc.) | `npm install patternomaly` |
| `@turf/turf` (with `turf-hatch`) | GIS‑oriented hatched polygons for maps. | `npm install @turf/turf` |
| `paper` (Paper.js) | Vector graphics framework with `Pattern` objects. | `npm install paper` |
| `fabric` (Fabric.js) | Canvas library supporting custom pattern fills. | `npm install fabric` |
| `leaflet-pattern` | Adds pattern fills to Leaflet map layers. | `npm install leaflet-pattern` |
| `svg-patterns` | Helper for building reusable SVG pattern definitions. | `npm install svg-patterns` |
| `canvas-sketch-util` | Utilities for procedural pattern fills in Canvas/WebGL sketches. | `npm install canvas-sketch-util` |
| `three` | Core 3D library used by this project (WebGPU, TSL). | `npm install three` |
| `@speckle/objectloader` | Loads Speckle objects for rendering in the web app. | `npm install @speckle/objectloader` |
